# CrystalScope

CrystalScope is a web application for crystal structure visualization and analysis.

Users can analyze crystal structures by:

* Uploading a CIF file
* Entering a Materials Project ID
* Entering a chemical formula

## Features

* Interactive 3D crystal structure visualization
* Chemical formula detection
* Density calculation
* Unit cell volume calculation
* Atom count
* Space group analysis
* Crystal system identification
* Lattice parameter extraction
* Supercell generation

## Technologies Used

* Python
* Streamlit
* Pymatgen
* Materials Project API
* Py3Dmol
* Pandas

## Run Locally

```bash
git clone <repository-url>
cd CrystalScope

pip install -r requirements.txt

streamlit run app.py
```
